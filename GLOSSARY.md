# На связи

Сервис, в котором гость выбирает тип события и свободное время,
чтобы забронировать встречу с владельцем календаря.

## Термины

**Владелец календаря**:
Человек, с которым гости бронируют встречи; он создаёт типы событий
и просматривает предстоящие встречи.
_Избегать_: администратор (это роль управления системой, а не название участника встречи).

**Гость**:
Человек, который бронирует встречу с владельцем календаря без аккаунта.
_Избегать_: посетитель, зарегистрированный пользователь, клиент (коммерческие отношения не определены).

**Тип события**:
Шаблон встречи с названием, описанием и длительностью.
_Избегать_: событие, слот, бронирование (это другие понятия).

**Слот**:
Интервал времени для встречи выбранного типа, длительность которого
определяется этим типом. Свободный слот доступен гостю для бронирования.
_Избегать_: событие, бронирование (это другие понятия).

**Бронирование**:
Оформленная встреча гостя с владельцем календаря на конкретное время.
_Избегать_: запись, слот (слот — интервал времени, а не оформленная встреча).

**Предстоящая встреча**:
Забронированная встреча, начало которой строго позже текущего времени.
Начавшаяся встреча уже не является предстоящей.
_Избегать_: незавершённая встреча (она может уже идти).

**Расписание**:
Общие для всех типов событий рабочие дни и интервалы времени владельца,
внутри которых могут проходить встречи.
_Избегать_: список бронирований (он отражает уже оформленные встречи).

**Окно записи**:
Период календарных дат, на которые гость может забронировать встречу:
сегодня и следующие 13 дней в часовом поясе календаря.
_Избегать_: 14 рабочих дней (выходные также входят в период).
