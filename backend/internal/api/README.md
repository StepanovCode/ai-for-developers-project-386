# HTTP API

Gin и HTTP DTO, маршруты в `router.go`, проверка формата входных
данных и преобразование ошибок в HTTP-статусы. `server.go` реализует
сгенерированный strict interface; `normalize.go` подготавливает входные
строки к schema validation, `errors.go` адаптирует ошибки. `handlers/` и
`middleware/` остаются местами для будущих отдельных обработчиков.

API вызывает usecase. За границу API передаются `context.Context` и обычные
типизированные данные; `gin.Context` остаётся здесь. Технический
`GET /api/health` реализован непосредственно в API; `NewRouter` возвращает
`http.Handler`, поэтому Gin не импортируется точкой входа и другими слоями.

Контракт, генерация и текущие ограничения описаны в [api/README](../../../api/README.md).
`generated/` обновляется только через `make generate`. В бизнес-слои эти
типы не передаются. Семь бизнес-операций пока явно возвращают ошибку 500;
их реализация относится к следующим тикетам.
