# Реализации доступа к хранилищам

Конкретные адаптеры хранения неявно удовлетворяют интерфейсам
потребителей из `usecase` или `services`. Не вызывают сценарии приложения
и не импортируют прикладные слои или API. Могут использовать типы `domain`.
Postgres сохраняет типы событий, реализуя интерфейс usecase.EventRepository
неявно. Миграции и их runner находятся в этом пакете; обычное открытие pool
не меняет схему. Фиктивных репозиториев и начальных данных нет.

ReadBusy читает только начало/окончание бронирований всех типов данного
владельца, пересекающих окно. Миграция 002 добавляет bookings без начальных
данных; публичная запись и exclusion constraint относятся к тикету 18.
