# Сценарии приложения

Пакет `usecase` координирует сервисы и репозитории. Прямой вызов репозитория
допустим через небольшой интерфейс, объявленный рядом с потребителем.
Конкретные реализации из `repo`, Gin, HTTP DTO и ORM сюда не импортируются.
Events реализует создание, каталог и чтение типа через EventRepository,
объявленный здесь. UUID v4 создаётся сценарием после доменной валидации; успех
возвращается только после подтверждённого сохранения репозиторием.

Slots владеет SlotRepository и Clock func() time.Time, один раз получает
серверное время, загружает тип и занятость владельца default для всего окна,
передаёт их чистому доменному расчёту. Ошибки хранилища сохраняет для API.
