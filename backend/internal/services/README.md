# Прикладные сервисы

Повторно используемые операции с самостоятельной ответственностью.
Доступ к репозиторию — через интерфейс рядом с потребителем. Нет зависимости
от `usecase`, конкретного `repo`, Gin или ORM. Сервис, только перенаправляющий
вызов репозиторию, не нужен. Чистые доменные правила относятся к `domain`.
