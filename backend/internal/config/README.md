# Конфигурация

Загрузка и проверка технических настроек приложения из окружения.
Используется точкой входа; не зависит от API, прикладных слоёв и хранилищ.
`config.go` читает и проверяет `PORT`, по умолчанию 8080. Compose задаёт
внутренний порт явно; внешний порт описан в корневом `.env.example`.

DATABASE_URL и OWNER_NAME задают хранилище и имя владельца. WORK_SCHEDULE
разбирается ParseSchedule: JSON-объект mon/tue/wed/thu/fri/sat/sun со списками
start/end в HH:MM. Пустая переменная означает пн–пт 09:00–18:00, пустой объект
закрывает все дни. Интервалы сортируются; некорректные часы, пересечения,
неизвестные дни/поля и ночные интервалы отклоняются. 24:00 допустимо как конец.
